# Badaba Studio website

Static site for Badaba Studio: the games (Coin Kitty / Kumbara Kedi, and Badaba Odd One Out / Badaba Farklı Olanı Bul at https://badaba-odd-one-out.web.app) and the Badaba YouTube channel (@badabakids).
Plain HTML and CSS, four languages (en, tr, es, fr), no cookies, no tracking, no external requests.

- Images: our own art from the games and the channel (`img/odd-one-out-*` are screenshots of that game, taken with its `--shot` option).
- Privacy policies: `kumbara-kedi/privacy/` and `odd-one-out/privacy/`, four languages each. Update a game's policy in the same change that gives that game a new kind of data.
- Fonts: Rubik Bold and Nunito (SIL Open Font License 1.1, licence texts in `fonts/`).

Published with GitHub Pages from `main`.
